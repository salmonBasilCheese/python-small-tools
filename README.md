# Python Small Tools

A collection of small Python utilities created for learning and automation.

## Tools

### rename_files.py

Adds the prefix `new_` to every file in a selected folder.

### duplicate_finder.py

Finds duplicate files in a folder using SHA-256 hashes.

### csv_sorter.py

Sorts CSV rows by the Score column in ascending order.

### image_resizer.py

Resizes image files in a selected folder.

### text_file_search.py

Searches for a specified string in `.txt` files in a selected folder.

### file_extension_counter.py

Counts files by extension in a selected folder.

### csv_filter.py

Filters CSV rows by a minimum Score and saves the matching rows to a new CSV file.

### file_size_checker.py

Displays the size of files in a selected folder and sorts them by size.

### large_file_finder.py

Finds files larger than a specified size in a selected folder.

### folder_report.py

Generates a report of files and folders, including file counts, total size, largest and smallest files, and file extension counts.

## Features

- Works on Windows
- Ignores subfolders
- Compatible with Python 3.13
- Uses Python standard libraries where possible
- Includes small practical utilities for file and data processing

## Purpose

This repository contains small Python projects created to improve programming skills and build a practical portfolio.
